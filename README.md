A program that draws a newspaper front page summing up the world news of
Wednesday 25 November 2026 and writes it to `/output/entry.png`
(1024×1024 PNG, about 20 KB). No network, no fonts, no image files: every
pixel is drawn in code (a 5×7 bitmap font, flat-shape pictograms, and a
hand-written PNG encoder), so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
